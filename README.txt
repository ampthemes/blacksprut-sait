HTML STATIC SITE — INSTRUKSI

1. Upload seluruh isi folder ini ke root hosting / Cloudflare Pages.
2. Tidak perlu Node.js, npm, Astro, database, atau proses build.
3. File sitemap.xml dan robots.txt sudah disertakan.
4. PENTING: ganti semua teks https://YOUR-DOMAIN.example dengan domain final Anda pada:
   - index.html
   - o-platforme/index.html
   - magaziny/index.html
   - instruktsiya/index.html
   - sitemap.xml
   - robots.txt
5. Header, footer, dan navigasi dimuat dari assets/js/layout.js.
6. CSS global hanya ada di assets/css/style.css.
7. URL halaman:
   / 
   /o-platforme/
   /magaziny/
   /instruktsiya/

Catatan:
Situs ini berupa portal informasi keselamatan digital. Tidak menyediakan tautan, mirror, registrasi, katalog transaksi, atau promosi untuk pasar ilegal.
